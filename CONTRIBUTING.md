# Contributing to Laternote

Thanks for your interest in improving Laternote!

## Before you start

- For anything bigger than a small fix, please open an issue first so we can agree on the approach.
- Keep pull requests focused: one change per PR.
- Run `flutter analyze` and `flutter test` before submitting.
